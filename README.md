# Reyon S Portfolio

A responsive single-page portfolio site for Reyon S, built with plain HTML, CSS, and JavaScript.

## Included
- Reference-inspired animated hero design with the clouds, illustrated character, laptop, books, learning-tool tiles, checklist, and target.
- Resume download button linked to `Reyon_S_Instructional Designer(LMS).pdf`.
- Work Samples link to the supplied Google Drive folder.
- About, services, skills, and contact sections.

The original ZIP is kept in the repository. The page loads its existing `assets/char.webp` character image from that ZIP in the browser.
